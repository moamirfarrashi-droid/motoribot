# بات آگهی موتورسیکلت دیوار → کانال تلگرام

هر روز آگهی‌های تازه‌ی موتورسیکلت رو از دیوار می‌گیره و با **همه‌ی عکس‌های آگهی
(به صورت آلبوم)** و کپشن با قالب کانالت پست می‌کنه:

```
🏍 SYM Galaxy J200 – جی ۲۰۰ گالکسی

📅 سال ساخت: ۱۴۰۳
🛣 کارکرد: ۱۰,۰۰۰ کیلومتر
📍 محل بازدید: تهران، آبشار
💰 قیمت: ۲۴۵ میلیون تومان

🔧 مشخصات و وضعیت:
• فنی سالم و آماده سواری
• مدارک کامل و آماده انتقال
```

و زیرش دکمه‌های «💬 ارتباط با پشتیبانی» و «🔗 مشاهده آگهی در دیوار».

بدون هیچ API هوش مصنوعی — قیمت خودکار «میلیون/میلیارد» میشه، بولت‌ها از
توضیحات خود آگهی ساخته میشن، و شماره‌تلفن‌های داخل توضیحات حذف میشن
(که مخاطب مجبور شه از دکمه پشتیبانی بیاد سراغ خودت).

---

## راه‌اندازی قدم به قدم

### قدم ۱ — ساخت ربات تلگرام (۲ دقیقه)
1. توی تلگرام برو به [@BotFather](https://t.me/BotFather) → دستور `/newbot` → یک اسم و یوزرنیم بده.
2. توکنی که میده (شبیه `123456:AAxx...`) رو کپی کن.
3. ربات رو به کانالت اضافه کن و **ادمین** کن (دسترسی Post Messages کافیه).
4. آیدی کانال:
   - کانال پابلیک: همون `@your_channel`
   - کانال پرایوت: یک پیام از کانال به [@JsonDumpBot](https://t.me/JsonDumpBot) فوروارد کن،
     عدد `chat.id` (که با `-100` شروع میشه) رو بردار.

### قدم ۲ — تنظیمات
```bash
cp .env.example .env
```
و سه مقدار اصلی رو پر کن: `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHANNEL_ID` و
`SUPPORT_TELEGRAM_URL` (لینک تلگرام پشتیبانیت مثل `https://t.me/your_id`).

### قدم ۳ — تست بدون پست کردن
```bash
pip install -r requirements.txt
python3 main.py --test
```
این فقط ۳ آگهی اول رو می‌گیره و کپشن‌شون رو توی ترمینال نشون میده — چیزی به
کانال پست نمیشه. برای تست یک آگهی خاص (مثلاً همون جویمکس):
```bash
python3 main.py --test-token gaqZf69e
```
> اگه تست خطا داد یا فیلدی (مثل کارکرد/عکس‌ها) خالی بود، خروجی رو برام
> بفرست تا پارسر رو با ساختار واقعی جواب دیوار تنظیم کنم — چون اندپوینت
> مستندنشده‌ست، ممکنه ساختارش کمی فرق داشته باشه.

### قدم ۴ — اجرای واقعی
```bash
python3 main.py
```

## اجرای خودکار روزانه — مقایسه‌ی گزینه‌ها (از ارزون به گرون)

| گزینه | هزینه | نکته مهم |
|---|---|---|
| **GitHub Actions** ⭐ | **رایگان کامل** | فایل ورک‌فلو آماده‌ست؛ فقط ریپو بساز و سکرت‌ها رو بذار. ریسک: ممکنه دیوار IP دیتاسنترهای خارجی رو محدود کنه — اول تستش کن |
| سرور ایرانی + کرون | ~ماهی ۱۰۰-۲۰۰ تومن | دیوار عالی کار می‌کنه ولی تلگرام مسدوده → باید `TELEGRAM_PROXY` تنظیم کنی |
| سرور خارجی ارزون + کرون | ~۳-۵ دلار/ماه | تلگرام مستقیم کار می‌کنه؛ دیوار معمولاً هم کار می‌کنه ولی تضمینی نیست |

**پیشنهادم:** اول GitHub Actions رو امتحان کن (مجانیه و ۱۰ دقیقه راه میفته).
اگه دیوار از IP گیت‌هاب جواب نداد، برو سراغ سرور.

### راه‌اندازی GitHub Actions (گزینه رایگان)
1. یک ریپوی **پرایوت** توی گیت‌هاب بساز و همه‌ی فایل‌های این پروژه رو پوش کن
   (فایل `.github/workflows/daily.yml` از قبل داخل پروژه هست).
2. توی ریپو برو: **Settings → Secrets and variables → Actions → New repository secret**
   و این سه تا رو بساز:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHANNEL_ID`
   - `SUPPORT_TELEGRAM_URL`
3. از تب **Actions**، ورک‌فلوی «Divar to Telegram - Daily» رو با دکمه
   **Run workflow** یک بار دستی اجرا کن و ببین پست‌ها میان یا نه.
4. از این به بعد هر روز ساعت ۹ صبح ایران خودش اجرا میشه. (ساعت رو می‌تونی
   توی `daily.yml` خط `cron` عوض کنی — به وقت UTC هست، ایران = UTC+3:30)
5. فایل `seen_posts.json` بعد از هر اجرا خودکار توی ریپو کامیت میشه که
   پست تکراری نره.

### راه‌اندازی روی سرور (کرون)
```bash
crontab -e
# هر روز ساعت ۹ صبح:
0 9 * * * cd /path/to/divar-telegram-bot && /usr/bin/python3 main.py >> log.txt 2>&1
```
اگه سرور ایرانه، توی `.env` مقدار `TELEGRAM_PROXY` رو با پروکسی خودت پر کن
(مثل `socks5h://127.0.0.1:1080`).

## تنظیمات قابل‌تغییر (فایل .env)
- `POST_MODE=album` → همه عکس‌ها به صورت آلبوم. چون تلگرام اجازه‌ی دکمه روی
  آلبوم رو نمیده، دکمه‌ها توی یک پیام کوتاه «برای خرید یا سوال 👇» بلافاصله
  زیر آلبوم (ریپلای روی آلبوم) میان.
- `POST_MODE=single` → فقط یک عکس، ولی دکمه‌ها مستقیم روی خود پست (تمیزتر).
- `MAX_IMAGES_PER_POST` → تعداد عکس آلبوم (سقف تلگرام ۱۰).
- `DIVAR_CITY_CODE` → 1=تهران، 2=کرج، 3=مشهد، 4=اصفهان، 5=شیراز، 6=تبریز
  (شهر دیگه‌ای خواستی بگو کدش رو دربیارم).
- `MAX_POSTS_PER_RUN` و `DELAY_BETWEEN_POSTS_SECONDS` → کنترل ریتم پست‌ها.

## ⚠️ نکات مهم که باید بدونی
1. **اندپوینت مستندنشده:** دیوار API رسمی برای جستجوی گروهی آگهی‌ها نداره؛
   این بات از همون اندپوینت داخلی خود سایت دیوار استفاده می‌کنه. یعنی ممکنه
   یک روز دیوار ساختارش رو عوض کنه و بات از کار بیفته (قابل تعمیره، ولی
   بدون هشدار قبلی اتفاق میفته).
2. **ریسک بلاک:** درخواست زیاد = احتمال بلاک IP. مقادیر پیش‌فرض محافظه‌کارانه
   تنظیم شدن؛ بیشترشون نکن مگه لازم باشه.
3. **قوانین دیوار:** برداشت خودکار محتوای آگهی‌ها ممکنه با شرایط استفاده‌ی
   دیوار در تناقض باشه. اگه کانالت جدی و درآمدزا شد، از طریق
   kenar.support@divar.ir با تیم دیوار هماهنگ کن.
4. **عکس‌ها:** بات URL عکس‌ها رو مستقیم از CDN دیوار به تلگرام میده (دانلود و
   آپلود مجدد نمی‌کنه)، پس سریع و کم‌مصرفه. اگه روزی دیوار هات‌لینک رو بست،
   باید دانلود/آپلود اضافه بشه — اونم شد بگو.
