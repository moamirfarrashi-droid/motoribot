دیجی‌هاینت — پست‌های آماده AI و خبر تازه فارسی

این بسته مکمل ریپازیتوری قبلی است: ۴۰ تصویر و پست آماده + خبر فارسی خودکار.
خبر تازه شامل تیتر و خلاصه کوتاه موجود در RSS است؛ ترجمه، تحلیل و فایده کسب‌وکاری ندارد.
نام و لینک رسانه در پست نمایش داده نمی‌شود؛ برای کنترل تکرار در سابقه داخلی نگهداری می‌شود.
نام اشخاص، شرکت‌ها و محصولات مربوط به خود خبر حفظ می‌شود.

نصب از وب:
۱. فایل‌ها را از ZIP استخراج کن و مستقیم در ریشه همان ریپازیتوری آپلود و Commit changes کن.
۲. اگر قبلاً این مکمل را نصب کرده‌ای، ai-publish.yml ریشه را به‌عنوان workflow دوم فعال نکن.
فایل .github/workflows/ai-publish.yml موجود را Edit کن و کل محتوایش را با ai-publish.yml داخل بسته جایگزین کن؛ سپس Commit changes.
۳. اگر نصب اول است، ai-publish.yml آپلودشده را باز کن، Edit بزن و نامش را به مسیر زیر تغییر بده:
.github/workflows/ai-publish.yml
۴. workflow شش‌پستی قدیمی (.github/workflows/publish.yml) سر جای خودش بماند.
۵. Actions > DigiHinet AI Daily > Run workflow:
برای خبر تازه: content=news / mode=test / slot=1 (day تاثیری ندارد)
برای پست تصویری آماده: content=ready / mode=test / day=1 / slot=1
کانال تست باید با کانال اصلی متفاوت باشد.

فعال‌سازی خودکار در Settings > Secrets and variables > Actions > Variables:
ENABLE_AI_POSTING = true برای روزی دو پست آماده
ENABLE_AI_NEWS = true برای روزی دو خبر تازه
مقصد خودکار: TELEGRAM_CHANNEL_ID؛ مقصد تست: TELEGRAM_TEST_CHANNEL_ID
بات باید ادمین مقصد و دارای مجوز ارسال باشد.

ساعت‌ها به وقت تهران:
پست آماده: ۱۰:۱۷ و ۲۰:۱۷ — برای ۲۰ روز از شروع مستقل این کمپین.
خبر روز: ۱۲:۱۷ و ۱۹:۱۷ — تا وقتی ENABLE_AI_NEWS فعال باشد؛ پس از ۲۰ روز قطع نمی‌شود.
با شش پست کمپین اصلی، دو پست آماده AI و دو خبر روز، مجموع حداکثر ۱۰ پست در روز است.
اجرای GitHub ممکن است دیرتر انجام شود. نوبت ازدست‌رفته خودکار جبران نمی‌شود.

انتخاب خبر:
خبرهای حداکثر ۴۸ ساعت اخیر از دیجیاتو، زومیت و هوشیو بررسی می‌شوند.
تیترهای فارسی مرتبط با AI و فناوری فیلتر می‌شوند؛ این انتخاب کلمه‌ای است و خطاپذیر.
خبرهای AI اولویت دارند، سپس موضوع‌های فناوری مانند نرم‌افزار، امنیت و ابزارها.
خبرهای بسیار مشابه در منابع مختلف و خبرهای قبلاً ارسال‌شده کنار گذاشته می‌شوند.
خبر بدون تاریخ معتبر یا با تاریخ آینده نامعتبر انتخاب نمی‌شود.
اگر خبر مناسب نبود، ارسال همان نوبت رد می‌شود. خبر قدیمی به‌عنوان تازه استفاده نمی‌شود.
خلاصه از RSS کوتاه می‌شود؛ بازنویسی هوشمند و تحلیل تولید نمی‌شود.
تصویر اختصاصی برای پست‌های آماده است؛ خبرهای زنده در این نسخه متنی‌اند.

حفاظت از سابقه:
این ZIP فایل سابقه ندارد. به state.json، campaign-state.json، ai-state.json و ai-news-state.json دست نزن.
اگر ارسال به تلگرام نامشخص باشد، pending جلوی ارسال بعدی را می‌گیرد؛ اول کانال و لاگ را بررسی کن.
در تست خبر، هر slot در هر روز فقط یک بار ارسال می‌شود؛ برای تست دوم slot=2 را بزن.

حالت preview هیچ خبری نمی‌فرستد و سابقه را تغییر نمی‌دهد.
پیش‌نمایش خبر و فهرست نامزدها در Artifacts همان اجرای Actions قرار می‌گیرد.
برای دیدن تصاویر آماده، ai-preview.html را روی کامپیوتر باز کن.
هیچ API تولید متن، کلید OpenAI یا سرویس ترجمه لازم نیست.
